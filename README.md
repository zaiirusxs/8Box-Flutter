🧩 Eight Images Tiles – Web & Mobile Prototype
📖 Short Description

Eight Images Tiles is a simple interactive project that displays eight image tiles arranged in a structured layout. The system demonstrates front-end layout design and basic interactive functionality. It serves as a practice project for understanding UI arrangement, file structure, and cross-platform development concepts.

The project includes both web and Dart components, showcasing flexibility in development environments.

✨ Features / Functionality

🖼️ Displays eight structured image tiles

📐 Organized grid layout design

🎨 Clean and simple user interface

🌐 Web-based interface using HTML

📱 Dart file structure for application logic

🛠️ Technologies Used

HTML – Structure of the webpage

CSS – Styling and layout design

Dart – Application logic

Android Studio Project Files (.iml) – Project configuration

🚀 Installation / Usage Instructions
🔹 For Web Version

Download or clone the repository.

Open the project folder.

Double-click index.html
OR
Open it using a browser.

🔹 For Dart / Android Version

Open the project in Android Studio.

Make sure Dart/Flutter SDK is installed.

Run the project using the emulator or a physical device.

🎯 Purpose

This project was developed as an academic exercise to practice UI layout structuring and basic application setup using both web and mobile development tools. It demonstrates understanding of file organization, front-end design, and basic cross-platform concepts.
